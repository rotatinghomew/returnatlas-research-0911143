# 资料服务接口

服务只在本机提供 JSON，响应编码为 UTF-8。查询接口不修改资料。

| 方法和路径 | 当前行为 |
| --- | --- |
| `GET /health` | 数据指纹和存活状态 |
| `GET /tables` | 表、字段类型和记录数 |
| `GET /tables/{name}?offset=0&limit=50` | 原始资料分页；偏移非负，每页一至五百行 |
| `GET /view` | 当前领域经营资料摘要 |
| `GET /profiles` | 数值字段的观察数、缺失数、中位数及绝对中位差 |
| `GET /clusters/scan` | 分层 Poisson 空间/时空聚集扫描，返回搜索校正后的复核线索 |
| `POST /cluster-reviews` | 固化扫描报告与引用证据为不可变复核存档 |
| `GET /cluster-reviews` | 复核存档索引 |
| `GET /cluster-reviews/{id}` | 校验完整性并回读复核存档 |
| `POST /cases` | 保存研究备注和当前完整资料副本；返回新记录 |
| `GET /cases` | 研究记录索引 |
| `GET /cases/{id}` | 校验完整性并回读记录 |

创建研究备注的字段为 `label`、`options` 和 `notes`，分别是名称、参数对象与说明文字。名称一至一百二十字，后两项可省略。不接受其他字段，不允许覆盖旧记录。记录 ID 由服务生成。资料指纹由原始数据和结构共同形成，不表示计算结果的统计可信度。

源表未找到或记录 ID 无效返回 404；字段或分页无效返回 400。默认监听 127.0.0.1:8080。服务当前提供资料浏览、数值探索、空间聚集复核线索和研究备注，不将保存备注视为已经完成经营分析。

## 空间聚集扫描

`GET /clusters/scan` 的统计口径见 `docs/cluster.md`，查询参数均可省略：

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `species` | 品种白名单，逗号分隔，例如 `species=鱼,虾` | 全部品种 |
| `week_from` / `week_to` | 履约周范围，ISO 周格式 `YYYY-Www` | 数据首末周 |
| `scenario` | 服务边界情景：`time_varying`、`fixed_earliest`、`fixed_latest` | `time_varying` |
| `mc` | 分层置换蒙特卡洛重复次数，零至九千九百九十九 | 399 |
| `realizations` | 街道候选点定位实现次数，零至五百 | 100 |
| `min_events` | 线索最少退货事件数 | 2 |
| `spatial_only` | `1` 表示只扫描空间窗，不枚举时间前缀 | `0` |
| `seed` | 随机种子，固定后结果可复现 | 7 |

报告只包含搜索校正 p 值不超过 0.05 的互不重叠线索；没有显著线索时 `clusters` 为空数组，但搜索网格、原假设分位阈值、无暴露位置清单和方法说明仍完整返回。参数非法返回 400。

`POST /cluster-reviews` 的请求字段为 `label`（一至一百二十字符）、`report`（完整扫描报告对象）和可选 `notes`，不接受其他字段。存档写入数据指纹、扫描参数、完整报告，以及报告引用到的配送单、联系记录、位置和全部服务边界原始记录，内容带 SHA-256 校验，不可覆盖。复核证据只到街道/路段级位置，不含住户标识。
