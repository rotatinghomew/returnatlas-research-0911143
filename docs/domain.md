# 配送覆盖资料约定

空间采用虚构本地坐标，不能当经纬度。不同位置候选共享同一配送单暴露，不能拆成多单。配送完成是风险分母可见的最低条件，订单返回与客服联系是不同实体。日期与配送范围按中国标准时间对齐。无配送记录区域表示没有观察到暴露，不表示风险为零。研究时间窗应考虑退货跟踪时间，末期订单可能尚未完成观察。

## 数据表

### `locations`

局部平面坐标，单位公里；候选位置带相对权重，单一位置的权重需在其支持内归一。不是实际个人地址。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `resolution` | `text` |
| `candidates` | `json` |

### `deliveries`

一行是一张配送单，未完成配送不进入完成订单暴露。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `day` | `date` |
| `location_id` | `text` |
| `species` | `text` |
| `delivered` | `bool` |
| `service_area` | `text` |
| `quantity_kg` | `number` |

### `contacts`

一项退货申请可产生多次联系；同一订单也可能有不同申请。计数单位必须指明订单、申请或联系。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `delivery_id` | `text` |
| `claim_id` | `text` |
| `day` | `date` |
| `action` | `text` |

### `service_areas`

配送服务可达边界，生效期左闭右开；不是销量或人口分母。

| 字段 | 解析类型 |
| --- | --- |
| `id` | `text` |
| `area_id` | `text` |
| `valid_from` | `date` |
| `valid_to` | `date` |
| `boundary` | `json` |

## 文件和数值语义

空单元格只在带问号的类型中表示缺失；零和空值不同。金额由十进制定点字符串保存，浮点数仅用于探索性统计。所有数据均为本地生成的虚构经营记录，不对应真实公司、客户或住址。数值剖面只反映观察数据，不能代替总体推断。

研究备注的参数为业务自由对象，不代表已执行了任何统计模型。原始表与已有视图可单独查询。

空间聚集复核线索（扫描口径、计数单位、分层、误报控制、地理不确定性与分辨率边界）见 `cluster.md`；其核心约束与本文件一致：完成配送才是可见暴露，无配送区域不代表零风险，订单、申请、联系是不同计数单位。
